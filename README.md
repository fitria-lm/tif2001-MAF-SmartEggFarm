## Latar Belakang
Pengelolaan peternakan ayam petelur membutuhkan pencatatan data operasional yang meliputi jumlah panen, pengeluaran, produksi telur, serta transaksi penjualan.
Apabila pencatatan masih dilakukan secara manual atau menggunakan media yang terpisah, proses pemantauan data menjadi kurang efisien dan berpotensi menimbulkan ketidaksesuaian data.

## Solusi Aplikasi
Smart Egg Farm merupakan sistem informasi manajemen peternakan ayam petelur berbasis web yang mengintegrasikan pencatatan kegiatan operasional, transaksi, dan berbagai data lainnya di peternakan dalam satu sistem.
Sistem memiliki berbagai fitur yang dijadikan halaman, antara lain :
1. Dashboard, berisi tampilan ringkasan seluruh data peternakan.
2. Kandang, berisi 4 sub-halaman:
    a. Data Kandang, berisi data ayam seperti populasi dan mortalitas ayam.
    b. Panen, berisi pengelolaan panen seperti input, edit, hapus, dan lihat data panen.
    c. Pakan, berisi manajemen stok pakan, kalkulator pakan, dan harga pakan
3. Pemasaran, berisi 3 sub-halaman:
    a. Penjualan Telur. Didalamnya terdapat fitur yang terbagi 3:  setting harga telur, input pencatatan order, antrean, dan orderan selesai
    b. Penjualan Lainnya. Didalamnya terdapat data penjualan sampingan. Seperti jagung dll.
4. Operasional
    a. Pengeluaran, berisi input dan table data pengeluaran
    b. Gaji Karyawan.

## Target Pengguna
### 1. Pemilik / Admin Peternakan
Memiliki akses untuk mengelola dan memantau seluruh data peternakan.
### 2. Karyawan Kandang
Menginputkan data panen dan mengakses kalkulator pakan.
### 3. Kasir
Mengelola transaksi penjualan.
